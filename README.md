# Forensic Ballistics Image Examination

**Author:** Aryan  

Upload two specimen images (cartridge case / toolmark photos). The app returns **MATCH**, **NO MATCH**, or **INCONCLUSIVE**, lists **similarities** and **differences**, and lets you download a printable **forensic examination report**.

**Live Space (after deploy):** `https://huggingface.co/spaces/aryan/forensic-ballistics-toolmark`
